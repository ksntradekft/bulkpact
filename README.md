# KSN Trade Nagyker – átmeneti GitHub/Vercel változat

Ez az alkalmazás a KSN Trade indulás előtti, statikus és reszponzív bemutató oldala. A termékkártyákhoz készült illusztrációk nem gyártói termékfotók. Nincs nyitott rendelésfelvétel, regisztráció vagy admin ezen a GitHub-változaton. A korábbi, külön elkészített teljes webshop-forráscsomag még külön telepítendő, és saját, új Supabase adatbázisra, képekre, árakra, jogi dokumentumokra és éles integrációkra van szüksége. Nem szabad a korábbi BulkPact vagy Private Label House adatbázisát használni.

Az eredeti BulkPact kód visszaállítható a `backup-bulkpact-2026-09-18` ágból.

## Indítás

`npm install && npm run dev`

Élesítés előtt ellenőrizd a Vercel deploymentet, a jogi adatokat és a domain beállításait. Az oldal szándékosan noindex, mert nem végleges webshop.
